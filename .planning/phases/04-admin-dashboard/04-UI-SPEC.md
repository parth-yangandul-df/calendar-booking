## Typography

| Role | Size | Weight | Line Height | Tailwind Class | Usage |
|------|------|--------|-------------|----------------|-------|
| Caption | 12px | 600 (semibold) | 1.5 | `text-xs font-semibold` | Table headers, admin badge, status badges |
| Body | 14px | 400 (regular) | 1.5 | `text-sm` | Table cell content, stat card labels, tab labels, empty state body |
| Heading | 20px | 600 (semibold) | 1.2 | `text-xl font-semibold` | Page title "Admin", empty state heading |
| Display | 30px | 600 (semibold) | 1.1 | `text-3xl font-semibold` | Stat card numerical values |

### Notes

- **Table header font:** `text-xs font-semibold text-muted-foreground` — matches calendar grid header pattern from MonthGrid.
- **Meta/secondary text:** `text-sm text-muted-foreground` — dates, timestamps, secondary info in table cells.
- **Stat card label:** `text-sm text-muted-foreground` — "Total users" / "Total bookings" label below the number.
- **Empty state:** Heading at `text-xl font-semibold` (20px — matching Heading role) + body at `text-sm text-muted-foreground`.
- **Admin badge in table:** `text-xs font-semibold` with `Badge variant="secondary"` (shadcn neutral badge style).

|--------|---------|
| Pending | `bg-amber-100 border-amber-300 text-amber-800` |

Use `Badge variant="secondary"` for admin status in users table. This renders as neutral/muted styling.

Accent reserved for: Stat card number values, page title, active tab selection, admin badge (via secondary variant contrast), any interactive elements (if added later).

## Component Layout

### Page Structure

```
/admin
├── Tabs (default="dashboard")
│   ├── Dashboard Tab
│   │   └── Stat cards row (2 cards: Total Users, Total Bookings)
│   ├── Users Tab
│   │   ├── Search input (email search)
│   │   ├── Table (Email | CreatedAt | IsAdmin | Bookings)
│   │   └── Pagination
│   └── Bookings Tab
│       ├── Status filter tabs (All / Pending / Confirmed / Declined / Cancelled)
│       ├── Table (Status | Owner | Booker | Date | Time | MeetUrl)
│       └── Pagination
```

### Dashboard Tab (D-03, D-04)

- Two stat cards in a horizontal row: `Total Users` (count) and `Total Bookings` (count)
- Each card: `Card size="sm"` → Display number (30px semibold) + label (14px muted)
- If both counts are 0, cards still render showing "0" — no separate empty state needed

### Users Tab (D-05, D-06, D-07, D-08)

- **Search bar:** `Input` with placeholder "Search by email…" at top of tab content
- **Table columns:** Email, CreatedAt (formatted date), IsAdmin (badge or dash), Bookings (count number)
- **Table behavior:** Read-only. No row click actions. No sort controls.
- **Pagination:** Below table. Page size 20.
- **Empty state:** "No users found" / "Try a different search term."
- **Loading state:** Skeleton rows or "Loading..." text (matching existing pattern: `text-sm text-muted-foreground`)

### Bookings Tab (D-09, D-10, D-11, D-12)

- **Status filter:** Nested `Tabs` (All/Pending/Confirmed/Declined/Cancelled) — matches the same Radix Tabs pattern used elsewhere
- **Table columns:** Status (badge), Owner (email), Booker (email), Date (ISO date), Time (`startTime–endTime`), MeetUrl (clickable link if present, dash if null)
- **Table behavior:** Read-only. No action buttons.
- **Pagination:** Below table. Page size 20.
- **Empty state per filter:** "No bookings found." / "There are no bookings matching this filter."
- **Loading state:** "Loading..." text.

### Navbar Integration (D-13, D-15, D-16)

- Navbar link added as the **last** nav item (after "Set Routine")
- Conditionally rendered: only when `user.isAdmin` is true (from `useAuth()`)
- Icon: `ShieldCheck` from lucide-react (`h-4 w-4`)
- Label: "Admin"
- Styling: matches existing nav links — `flex items-center gap-1 text-sm hover:text-primary`
- Position: `<ShieldCheck className="h-4 w-4" />` + "Admin"

### Admin Guard (D-14)

- Route-level guard component (e.g., `AdminRoute` wrapping `ProtectedRoute` pattern)
- Checks `user.isAdmin` — if false, redirect to `/` and show Sonner toast: "You don't have permission to access this page."
- If loading, returns null (matches ProtectedRoute pattern for auth check)
