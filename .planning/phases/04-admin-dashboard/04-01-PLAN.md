    **Part A — AdminController.cs** at route `api/v1/admin`:

    ```
    [ApiController]
    [Route("api/v1/admin")]
    [Authorize(Policy = "AdminOnly")]
    ```

    Inject `UserManager<ApplicationUser> _userManager` and `ApplicationDbContext _context` via constructor (no service layer needed for simple read queries).

    Helper: `private string GetUserId() => _userManager.GetUserId(User)!;` — same pattern as BookingController line 34.

    **Endpoint 1 — GET /stats** (D-24):
    - Query `await _userManager.Users.CountAsync()` for total users
    - Query `await _context.Bookings.CountAsync()` for total bookings
    - Return `Ok(new AdminStatsDto(totalUsers, totalBookings))`

    **Endpoint 2 — GET /users** (D-22):
    - Query params: `[FromQuery] int page = 1`, `[FromQuery] int pageSize = 20`, `[FromQuery] string? search`
    - Build query from `_userManager.Users.AsQueryable()`:
      - If `search` is non-null and non-whitespace, add `.Where(u => u.Email!.Contains(search))`
    - Count: `var totalCount = await query.CountAsync()`
    - Paginate: `.OrderBy(u => u.Email).Skip((page - 1) * pageSize).Take(pageSize)`
    - Execute to list: `var users = await query.ToListAsync()`
    - Build booking count map: query `_context.Bookings` grouped by `OwnerId`, project to dictionary `{ OwnerId -> Count }`
    - Map to `AdminUserDto` list using user's fields and booking count from map
    - Return `Ok(new PagedResponse<AdminUserDto>(items, totalCount, page, pageSize))`
    - Edge: if `page < 1`, default to 1. If `pageSize < 1`, default to 20. If `pageSize > 100`, cap at 100.

    **Endpoint 3 — GET /bookings** (D-23):
    - Query params: `[FromQuery] int page = 1`, `[FromQuery] int pageSize = 20`, `[FromQuery] string? status`
    - Build query from `_context.Bookings.AsQueryable()`:
      - If `status` is non-null, attempt `Enum.TryParse<BookingStatus>(status, true, out var bookingStatus)`. If parse succeeds, add `.Where(b => b.Status == bookingStatus)`. If parse fails, ignore the filter (don't return error — just return all).
    - Count: `var totalCount = await query.CountAsync()`
    - Paginate: `.OrderByDescending(b => b.Date).ThenByDescending(b => b.StartTime).Skip((page - 1) * pageSize).Take(pageSize)`
    - Execute to list
    - Collect all unique OwnerId + BookerId from the result set, query `_userManager.Users` to build `Dictionary<string, string>` id→email map
    - Map to `AdminBookingDto` list using booking fields and email map
    - Return `Ok(new PagedResponse<AdminBookingDto>(items, totalCount, page, pageSize))`
    - Edge: same page/pageSize guards as /users endpoint.
