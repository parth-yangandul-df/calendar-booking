**Create AvailabilityRepository.cs** in `src/backend/Infrastructure/Repositories/AvailabilityRepository.cs`:
- Namespace: `CalendarBooking.Infrastructure.Repositories`
- Class `AvailabilityRepository : IAvailabilityRepository`
- Constructor takes `ApplicationDbContext _context`
- Implement all 6 interface methods:

  1. **GetTemplateAsync(userId):** `return await _context.WeeklyTemplates.Where(wt => wt.UserId == userId).ToListAsync();`

  2. **SetTemplateAsync(userId, items):** Execute as a full-replace within a transaction (per D-18 PUT semantics):
     ```csharp
     var existing = await _context.WeeklyTemplates.Where(wt => wt.UserId == userId).ToListAsync();
     _context.WeeklyTemplates.RemoveRange(existing);
     var newRows = items.Select(i => new WeeklyTemplate
     {
         UserId = userId,
         DayOfWeek = Enum.Parse<DayOfWeek>(i.DayOfWeek),
         StartTime = TimeOnly.Parse(i.Start),
         EndTime = TimeOnly.Parse(i.End)
     }).ToList();
     await _context.WeeklyTemplates.AddRangeAsync(newRows);
     await _context.SaveChangesAsync();
     ```

  3. **GetOverridesAsync(userId, from, to):** `return await _context.AvailabilityOverrides.Where(ao => ao.UserId == userId && ao.Date >= from && ao.Date <= to).ToListAsync();`

  4. **SetOverrideAsync(userId, date, items):** Full-replace per day (per Research Pitfall 2 — send entire day's state, prevents race conditions):
     ```csharp
     var existing = await _context.AvailabilityOverrides
         .Where(ao => ao.UserId == userId && ao.Date == date)
         .ToListAsync();
     _context.AvailabilityOverrides.RemoveRange(existing);
     var newRows = items.Select(i => new AvailabilityOverride
     {
         UserId = userId,
         Date = date,
         StartTime = TimeOnly.Parse(i.Start),
         EndTime = TimeOnly.Parse(i.End)
     }).ToList();
     await _context.AvailabilityOverrides.AddRangeAsync(newRows);
     await _context.SaveChangesAsync();
     ```

  5. **DeleteOverrideAsync(userId, date, overrideId):**
     ```csharp
     var override = await _context.AvailabilityOverrides
         .FirstOrDefaultAsync(ao => ao.Id == overrideId && ao.UserId == userId && ao.Date == date);
     if (override != null) { _context.AvailabilityOverrides.Remove(override); await _context.SaveChangesAsync(); }
     ```

  6. **GetCalendarAsync(userId, month):** Per RESEARCH.md calendar merging logic:
     - Parse month "YYYY-MM" into `year` and `monthNum` ints
     - Create `var startDate = new DateOnly(year, monthNum, 1);`
     - Create `var endDate = startDate.AddMonths(1).AddDays(-1);`
     - Fetch template: `await _context.WeeklyTemplates.Where(wt => wt.UserId == userId).ToListAsync();`
     - Fetch overrides: `await _context.AvailabilityOverrides.Where(ao => ao.UserId == userId && ao.Date >= startDate && ao.Date <= endDate).ToListAsync();`
     - Iterate each day in [startDate, endDate]:
       - Check for overrides on that date -> if found: `CalendarDayDto(dateStr, true, overrides.Select(...TimeRangeDto...))`
       - Check template for that DayOfWeek -> if found: `CalendarDayDto(dateStr, false, template.Select(...TimeRangeDto...))`
       - If neither: `CalendarDayDto(dateStr, false, empty list)`
     - Return `List<CalendarDayDto>`
