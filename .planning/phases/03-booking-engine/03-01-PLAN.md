    SELECT 1 FROM Bookings WITH (UPDLOCK, ROWLOCK) WHERE OwnerId = @ownerId AND Date = @date AND Status IN (0, 1) AND ((StartTime < @endTime AND EndTime > @startTime))

Recommended pattern: use _context.Database.BeginTransactionAsync(); then var conflicts = await _context.Bookings.FromSqlRaw("SELECT * FROM Bookings WITH (UPDLOCK, ROWLOCK) WHERE OwnerId={0} AND Date={1} AND Status IN (0,1) AND StartTime < {2} AND EndTime > {3}", ownerId, date, endTime, startTime).CountAsync(); if conflicts > 0 { await tx.RollbackAsync(); return null; } else { add + save + commit; return booking; }.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → POST /api/v1/bookings | OwnerId is user-supplied — must validate owner exists and is not the caller |
| client → PATCH accept/decline | Caller must be verified as the booking owner — not just any authenticated user |
| client → DELETE | Caller must be verified as OwnerId or BookerId — not a third party |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | POST /api/v1/bookings OwnerId field | mitigate | Server ignores supplied BookerId — always derives from JWT via GetUserId() |
| T-03-02 | Tampering | PATCH accept/decline | mitigate | Server verifies booking.OwnerId == GetUserId() before accepting; 403 otherwise |
| T-03-03 | Tampering | DELETE /api/v1/bookings/{id} | mitigate | Server verifies caller is OwnerId or BookerId; 403 otherwise |
| T-03-04 | Elevation of Privilege | Booking own calendar | mitigate | POST rejects when OwnerId == BookerId; 400 "Cannot book your own calendar" |
| T-03-05 | Denial of Service | Race condition / double-booking | mitigate | UPDLOCK+ROWLOCK pessimistic locking; only one writer succeeds per slot |
| T-03-06 | Information Disclosure | GET /api/v1/bookings returns all bookings | mitigate | Returns only bookings where caller is OwnerId or BookerId — no cross-user leakage |
| T-03-SC | Tampering | NuGet package installs (Hangfire) | accept | Hangfire.SqlServer is a well-known package — no install occurs in this plan |
</threat_model>
