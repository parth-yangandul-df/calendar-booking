## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hangfire dashboard → /hangfire | Exposes job queue internals — must not be accessible to unauthenticated users in production |
| EmailService → SMTP provider | SMTP credentials in env vars — never in code or source-controlled config files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Information Disclosure | Hangfire dashboard /hangfire | accept (dev only) | Dashboard is dev-only; production deployment must restrict with [Authorize(Roles="Admin")] or firewall rule |
| T-03-08 | Information Disclosure | SMTP credentials in config | mitigate | Credentials read from env vars (Email:Host etc.); appsettings.json contains only placeholder/empty values; never committed |
| T-03-09 | Tampering | Hangfire SQL job store | accept | Hangfire jobs are enqueued by authenticated code paths only; SQL Server is internal network |
| T-03-SC | Tampering | Hangfire NuGet packages | mitigate | Hangfire.SqlServer is a well-known, widely-used package (>200M NuGet downloads); verify package source is nuget.org |
</threat_model>
